# 🍯 عسل عُمان الأصيل

موقع ثابت (HTML / CSS / JavaScript) لبيع العسل العماني واستقبال الطلبات عبر **واتساب**، مع تحديد
**المحافظة والولاية والقرية ومكان التوصيل** (GPS أو رابط خرائط Google).

## المميزات
- عرض المنتجات (سدر، سمر، برم، غاف، زهور جبلية) بأحجام وأسعار قابلة للتعديل.
- سلة طلبات وحساب الإجمالي تلقائياً.
- قوائم جميع محافظات سلطنة عُمان (11) وولاياتها، وحقل للقرية/المنطقة.
- زر «حدّد موقعي» يأخذ إحداثيات GPS ويضيف رابط الخريطة للطلب.
- إرسال الطلب كرسالة واتساب جاهزة برقم طلب فريد.
- زر تواصل عائم عبر واتساب.
- تصميم عربي (RTL) متجاوب مع الجوال.

## الإعداد
1. افتح `js/config.js` وضع رقم الواتساب بالصيغة الدولية بدون `+`:
   ```js
   whatsappNumber: "96891234567",
   ```
2. عدّل المنتجات والأسعار من `js/products.js`.
3. قائمة المحافظات والولايات في `js/oman-locations.js`.

## النشر على GitHub Pages
Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
سيعمل الموقع على: `https://<username>.github.io/<repo-name>/`

> ملاحظة: زر «حدّد موقعي» يحتاج HTTPS، وهو متوفر تلقائياً في GitHub Pages.

## الحماية
راجع [SECURITY.md](SECURITY.md).
